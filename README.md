# Crystal Pay

Bill payments, a buy-and-sell marketplace and a Naira wallet.

| Folder | |
| --- | --- |
| `app` | Android app (Flutter) |
| `admin` | Operations dashboard (React + Vite) |

## Development

```bash
# app
cd app
flutter pub get
flutter run

# admin
cd admin
npm ci
npm run dev
```

Signing keys and environment values are not stored in this repository.
